# 採寸表（同梱モジュール size_charts）

商品ページに、サイズごとの寸法の表（着丈・身幅・肩幅…）と**測り方の図**を出すモジュールです。
**ショップ全体・カテゴリー・商品**の 3 つの段で決められ、商品はいちばん近い段の表を使います。
よくある使い方は「カテゴリー（トップス）で項目と単位と図を決め、商品ごとに S・M・L の値だけを入れる」です。

- 既定は OFF です。管理画面 → ショップ → モジュール →「採寸表」を ON にします（データベースの変更 `0095_mod_size_charts` が要ります）。
- 表の項目は自由です。列ごとに単位（cm・mm・inch・号 など）を変えられます。セルの値は文字なので「38〜40」「F」も入れられます。
- お客様の画面に出すかどうかは、モジュールの ON / OFF で決まります。OFF にしても入れた表は消えません。

## どの段の表を使うか

表は「列（項目と単位）・図・結ぶ軸」と「行（サイズごとの値）・注記」の 2 つに分けて決めます。

1. **列・図・結ぶ軸**: 商品 → 主カテゴリー（子から親へ）→ ショップ全体の順に見て、**列を決めた最初の段**のもの。
2. **行・注記**: 商品から 1. の段までのあいだで、**行（注記）を決めた最初の段**のもの。1. より上の段の行は使いません（列と合わないため）。

| 例 | ショップ全体 | カテゴリー「トップス」 | 商品 | 出る表 |
| --- | --- | --- | --- | --- |
| カテゴリーで型、商品で値 | — | 列・図 | 行 | トップスの列と図、商品の行 |
| カテゴリーで値まで | — | 列・図・行 | — | トップスの表そのもの |
| 商品だけ別の型 | — | 列・図・行 | 列・行 | 商品の表（トップスの図は出ない） |
| この商品には出さない | — | 列・図・行 | 「出さない」 | 出ない |

カテゴリーは主カテゴリーだけを見ます（追加カテゴリーは見ません）。どの段から来たかは、編集の画面の「お店の画面に出る表」に出ます。

## 管理画面

- **ショップ全体**: モジュールの一覧の「採寸表」→「開く」。
- **カテゴリー**: カテゴリーの一覧の各行の「採寸表」。
- **商品**: 商品の画面の上の「採寸表」。

それぞれの画面で「この段で列を決める」「この段で行を決める」を選びます。選ばない部分は上の段のものを使います。欄に入力すると、そのチェックは自動で付きます（その段にまだ無いものに入力したときは、チェックが無くてもその段のものとして保存します）。すでにその段で決めていて、上の段に戻したいときはチェックを外して保存します。
その段に行が無いあいだは、上の段の行が欄に薄い字で出ます（入力しない限り、そちらが使われます）。

**寸法が商品ごとに違うもの（洋服・ねじ・釘など）は、カテゴリーで列と図だけを決め、行は入れずに、商品ごとに値を入れる**のがおすすめです。カテゴリーに行を入れると、値を入れていない商品にはその行が出ます（全部の商品で同じ表を出したいとき向け）。

- **列**: 項目（40 文字まで）と単位（10 文字まで）、12 列まで。項目を空にした列は消えます。項目の名前を変えても、入れた値はそのまま残ります（列には変わらない鍵が付いています）。
- **行**: 1 列目がサイズ（40 文字まで、同じサイズは 1 行だけ）、60 行まで。表計算ソフトからタブ区切りで貼り付けられます（1 行目が見出しなら飛ばします）。
- **結ぶ SKU の軸**: SKU を分ける軸（サイズなど）を選ぶと、お客様が選んだ SKU の行を目立たせます。行のサイズと SKU の選択肢の値が同じ（大文字小文字は区別しない）ときです。
- **測り方の図**: JPEG・PNG・WebP。ブラウザで横幅 1600px までの WebP に縮小してから送ります（スクリプトが使えないときはそのまま、5MB・4096px まで）。図は商品画像と同じ置き場の `size-charts/<ショップ>/` に置き、差し替えると前の図は消します。図は列を決めた段のものが出ます。
- **注記**: 「平置きで測っています。1〜2cm の誤差があります」など（2,000 文字まで）。
- **この商品には出さない**（商品の段だけ）: カテゴリーに表があっても、小物などには出さないとき。

扱えるのは権限の項目「商品（catalog）」を持つ人です。

## お店の画面

- **既定のテーマ**: 商品ページの商品の下に「サイズ」の表と注記・図を出します。横に長い表は枠の中だけ横に動きます。選んだ SKU の行は目立ちます（選び直すとスクリプトが付け替えます）。
- **Liquid のテーマ**（docs/themes.md）: `product.size_chart`。無ければ `nil`。

  | 項目 | 中身 |
  | --- | --- |
  | `axis` / `axis_name` | 結んだ SKU の軸の key と表示名（結んでいなければ `nil` / 空） |
  | `columns` | 列（`key`・`label`・`unit`・`heading`（「着丈（cm）」）） |
  | `rows` | 行（`value`・`cells`（列と同じ並びの配列）・`cells_by_key`・`selected`（選んだ SKU の行か）） |
  | `note` | 注記（無ければ空） |
  | `image` | 図（`src`・`width`・`height`）。無ければ `nil` |

  ```liquid
  {% if product.size_chart %}
    <table>
      <tr><th>{{ product.size_chart.axis_name | default: 'サイズ' }}</th>{% for c in product.size_chart.columns %}<th>{{ c.heading }}</th>{% endfor %}</tr>
      {% for row in product.size_chart.rows %}
        <tr{% if row.selected %} class="selected"{% endif %}><th>{{ row.value }}</th>{% for cell in row.cells %}<td>{{ cell }}</td>{% endfor %}</tr>
      {% endfor %}
    </table>
  {% endif %}
  ```

- **ヘッドレス**（docs/headless.md）: 公開 API の商品（`GET /api/shops/<ショップ>/products/<スラッグ>`）の `size_chart`（`axis`・`axis_name`・`columns`・`rows`（`cells` は列の key → 値）・`note`・`image`（`url`・`width`・`height`））。どの段の表かは Banto が決めたものです。

## AI 用 API

- `GET /api/v1/size-chart?product_id=…`（`?category_id=…`、どちらも無ければショップ全体の段）: products:read。`own` はその段に置いたもの、`effective` はお店の画面に出る表。
- `PUT /api/v1/size-chart?product_id=…`: products:write。その段を置き換えます。

  ```json
  { "columns": [{ "key": "length", "label": "着丈", "unit": "cm" }, { "label": "身幅", "unit": "cm" }],
    "rows": [{ "value": "M", "cells": { "length": "70", "c2": "52" } }],
    "axis": "サイズ", "note": "平置きで測っています" }
  ```

  列の `key` は英小文字（省略すると `c1`・`c2`…の順に振ります）。行の `cells` は列の key で書きます。`null` の項目（`columns`・`rows`・`note`）はその段では決めず、上の段を使います。中身がすべて空なら段を消します。`hidden: true` は商品の段だけ。**図は API では変えません**（管理画面で置きます）。
- MCP: `size_chart_get` / `size_chart_set`【書き込み】。

## しくみ（開発者向け）

- 表 `size_charts`（1 行 = 1 つの段）。書き込みは RPC（`size_chart_set`・`api_size_chart_set`）だけで、形は `banto_size_chart_normalize` が知っている鍵だけに組み直します。
- どの段の表を使うかは `banto_size_chart_resolve` だけが決めます。お客様の画面は `product_public_get` の `size_chart`（モジュールが ON のときだけ）で、DB の往復は増えません。
- 画面の部品は `src/size-charts/`（`chart.ts` が読み取り・貼り付け・Liquid と API の形、`html.tsx` が既定のテーマの表）。管理画面は `src/modules/size-charts/admin.tsx`。
- バックアップの書き出しに `size_charts` が入ります（図の実体は商品画像と同じく含みません）。
