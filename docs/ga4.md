# Google アナリティクス（GA4）（同梱モジュール）

Banto のお店の画面に、運営者自身の GA4 のタグを入れます。既定は OFF です。

## 使い方

1. GA4 でプロパティとウェブのデータストリームを作り、**測定 ID**（`G-` から始まる）を控える（GA4 の「管理 → データストリーム」）。
2. 管理画面 → ショップ → **モジュール** →「Google アナリティクス（GA4）」を ON にする。
3. モジュールの画面で測定 ID を入れて保存する（DB の更新 0041 が要ります）。空にすると外します。

## 送るもの

ページビューと、EC のイベントです。Banto の本体が積んだ出来事（docs/storefront.md §2）を、このモジュールが GA4 の形にします。

| GA4 のイベント | いつ | 内容 |
| --- | --- | --- |
| `view_item` | 商品ページを開いた | SKU ごとの品番（`item_id`）・名前・価格 |
| `add_to_cart` | カートに入れた直後の商品ページ | 入れた SKU と数量 |
| `view_cart` | カートを開いた | カートの中身と合計 |
| `begin_checkout` | 最終確認画面を開いた | 明細と支払う額 |
| `purchase` | 決済後の完了画面で、注文の確定が確かめられた | 注文番号（`transaction_id`）と支払った額 |

- 氏名・メールアドレス・住所などの個人情報は送りません。
- `purchase` は完了画面を開き直しても、GA4 が同じ注文番号を 1 回として数えます。
- 送り先は運営者自身の GA4 です。Banto の開発チームには何も送りません（テレメトリは無い、CLAUDE.md §1-9）。
- 管理画面には入れません。

## プライバシーポリシー

GA4 は Cookie を使います。ショップ設定のプライバシーポリシーに、Google アナリティクスを使っていること・目的・止め方（[Google アナリティクス オプトアウト アドオン](https://tools.google.com/dlpage/gaoptout)）を書いてください。

## 外のサイトと合わせて使う

「カートと購入だけ Banto の画面を使う」（docs/storefront.md）で商品を外のサイトで紹介しているときは、外のサイトの GA4 と同じ測定 ID を入れると、商品を見てから購入までを 1 つのプロパティで見られます（ドメインが違うときは GA4 の「クロスドメイン測定」の設定も必要です）。
