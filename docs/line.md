# LINE（公式アカウントでの通知）

Banto は LINE の **Messaging API** で 2 種類の通知を送れます（どちらも同梱プラグイン、既定 OFF）。

| プラグイン | 送る相手 | 送る内容 |
| --- | --- | --- |
| LINE 通知 | 運営者（設定した利用者 ID） | 新しい注文・キャンセル・在庫僅少（購入者の個人情報は送らない） |
| LINE で購入者に知らせる | **LINE でログインした会員** | 注文の受付（注文番号・合計）・発送 |

## 1. チャネルアクセストークン（ショップごと）

1. LINE Developers で、ショップの LINE 公式アカウントの **Messaging API チャネル** を開きます（無ければ LINE Official Account Manager で公式アカウントを作り、Messaging API を有効にします）。
2. 「Messaging API 設定」の **チャネルアクセストークン（長期）** を発行します。
3. 管理画面 → ショップ → プラグイン →「LINE 公式アカウント」に貼って保存します。
   - サイトの秘密（`SESSION_SECRET`）から作った鍵で **暗号化して** 保存し、画面には二度と出しません（CLAUDE.md §1-5 の例外、メンテナの決定 2026-10-17）。`SESSION_SECRET` を変えたら入れ直してください。
   - 入れなければ、変数とシークレットの `LINE_CHANNEL_ACCESS_TOKEN` を使います（ショップが 1 つだけの運営なら、こちらでも構いません）。

データベースの更新 `0021_line_messaging` が要ります。

## 2. 購入者に知らせる

1. **LINE でログイン** のモジュールを設定します（docs/members.md 3-3）。
2. LINE ログインのチャネルと Messaging API のチャネルを **同じプロバイダー** に置きます。プロバイダーが違うと、会員の LINE の利用者 ID が合わず届きません。
3. LINE でログインのモジュールの画面で **「友だち追加を促す」** を選びます。公式アカウントを友だちに追加していない人には届かないためです。
   - 「同意の画面に、友だち追加のチェックを出す」（`bot_prompt=normal`）か「同意の後に、友だち追加の画面を開く」（`bot_prompt=aggressive`）。
4. プラグインの画面で「LINE で購入者に知らせる」を有効にします。

- 知らせるのは、LINE と結びついた会員の注文だけです（ゲスト・メールだけの会員には送りません。メールの通知は「メール通知」プラグイン）。
- 文に載せるのは注文番号・合計・ショップ名だけです（住所・氏名は載せません）。
- 友だちでない・ブロックされた人に送れなかったときは、失敗にしません（再送しても届かないため）。
