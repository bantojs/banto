# 商品画像の大きさ

商品画像は、アップロードのときに **管理画面のブラウザ** が縮小して WebP にします（Banto のサーバーは画像を加工しません。Workers の CPU の制限と、Cloudflare 固有の機能に頼らないため）。

## 作る大きさ

1 枚の画像から、**横幅**がそれぞれ次の大きさの画像を作ります（縦長の写真でも横幅がそろいます）。元の写真がそれより小さければ、元の大きさまでです。

| 段 | 横幅 | 使うところ |
| --- | --- | --- |
| サムネイル | 400px | 一覧のカード・小さな画面 |
| 中間 | 800px・1600px・2048px・2560px のうち本画像より狭いもの | 画面の幅に合わせて |
| 本画像 | ショップの設定（既定 1600px） | 大きな画面・拡大 |

どの段も**高さは 4096px まで**です。商品説明の縦長の画像（1:5 など）は、高さ 4096px に合わせて縮めます（そのぶん横幅は狭くなります）。

お客様の画面は、端末の画面の幅と密度に合う段をブラウザが選びます（`srcset`）。本画像を大きくしても、一覧やスマホで重い画像が落ちてくることはありません。

## 大きさを変える

管理画面 → ショップ →「商品画像の大きさ（横幅）」で、**1600px（既定）・2048px・2560px・3200px** から選びます。

- 生地・作品の細部などを拡大して見せたいときは 2048px 以上にしてください。
- **これから上げる画像から**効きます。前に上げた画像はそのままです（大きくしたいときは上げ直してください）。
- 大きくすると、アップロードに少し時間がかかり、画像の置き場（R2）の量が増えます（1 枚あたり数百 KB〜数 MB）。本画像は 1 枚 5 MB までです。

## 外部の変換プラグインに任せる

管理画面 → ショップ →「商品画像の変換」で選びます（データベースの更新 `0092_image_processing` が要ります）。

| 選び方 | アップロードのとき | 本画像と中間の段 | 費用 |
| --- | --- | --- | --- |
| ブラウザで変換する（既定） | ブラウザが全部の段を作ってから送る（待つ） | 上げた時点でそろう | 0 |
| 外部の変換プラグインに任せる | 元の写真とサムネイル（横幅 400px）だけを送る（待たない）。元の写真は 20MB まで | 画像を変換できる外部プラグインが数分のうちに作って差し替える | プラグインの側の変換の料金 |

- 任せるには、マニフェストの `capabilities` に `"images"` を書いた外部プラグイン（例: [bantojs/banto-plugin-webp](https://github.com/bantojs/banto-plugin-webp)）をつないでください（docs/hooks.md）。つながっていないと、管理画面が知らせます。
- プラグインは `product.updated`（画像を足すと届きます）と `GET /api/v1/image-settings` で作る段を決め、`PUT /api/v1/images/{id}/file` で本画像・サムネイル・中間の段を差し替えます（docs/api.md）。
- 変換が終わるまでのあいだ、お店の画面には元の写真が出ます（一覧はサムネイルで軽いまま）。商品を公開する前に上げておくと安心です。
- 回線が遅い場所（外出先のスマホなど）では、元の写真を送る時間のほうが長くなることがあります。

## テーマ

- 既定のテーマは、一覧と商品ページの画像に持っている段をすべて `srcset` で出します。
- Liquid のテーマの `image_url: width: 600` は、求めた幅以上でいちばん小さい段を返します。`image_tag` は求めた幅までの段を `srcset` に入れます（`sizes` を渡すと、端末に合う段が選ばれます）。

## そのほか

- GIF（動く画像）はそのまま置きます。
- AI 用の API で URL や ファイルから取り込んだ画像、WooCommerce から裏で取り込んだ画像は、中間の段を持ちません（サムネイルと本画像だけ。docs/api.md）。WooCommerce の取り込みの画面で縮小して取り込む画像は、中間の段も作ります。
- 中間の段はデータベースの更新 `0091_image_variants` が要ります。当たるまでは、前と同じ本画像とサムネイルだけを作ります。
- 0091 より前に上げた画像のサムネイルは長辺 400px で作っています（縦長の写真なら横幅は 400px より狭い）。表示はそれを見分けて正しい幅で `srcset` を出します。
