# クーポン（同梱モジュール）

購入者がコードを入力すると値引きされるクーポンです。モジュールは既定で OFF なので、使うときだけ ON にします。
値引きの判定と回数の数え方は Banto のコア（カート・確認画面・確定の一本道）が行います。モジュールは、クーポンを登録する画面です。

## 1. 準備

1. 管理画面 → アップデートで、データベースの更新 `0010_coupons` を適用します。
2. ショップ設定 → **モジュール** → 「クーポン」を **ON** にします。
3. ショップ設定に「クーポン」のリンクが出るので、開いて「新しいクーポン」を作ります。

## 2. 設定できること

| 項目 | 内容 |
| --- | --- |
| コード | 購入者が入力する文字列。英数字・ハイフン・アンダースコア（32 文字まで）。大文字に揃えます |
| 種類と値 | 割合（1〜100%）/ 定額（円）/ 送料無料。割合と定額は **対象商品の金額にだけ** かかり、1 円未満は切り捨てます |
| 併用 | 「他のクーポンと併用できる」にしたものどうしだけ、1 注文に重ねて使えます（最大 5 枚）。併用できないクーポンは 1 枚だけで使います |
| 期間 | 開始・終了（運営者の時間帯。既定は日本時間）。空なら期間なし |
| 全体の上限（先着） | 何回まで使えるか。上限ちょうどで止まり、同時に申し込まれても超えません |
| 1 人あたりの上限 | 会員は会員 ID、ゲストは注文のメールアドレスで数えます |
| 使える人 | 誰でも / ログイン中の会員だけ（会員機能を有効にしたショップ） |
| 対象 | 商品（スラッグで指定）・カテゴリー（子のカテゴリーと追加カテゴリーを含む）・タグ・ブランドを「対象にする」「除く」、セール品（通常価格が付いている SKU）を除く |
| 条件 | 対象商品の合計の下限・上限（円、値引き前・税込）、対象商品の点数の下限 |
| 支払い方法 | 使える支払い方法を絞る（Stripe / KOMOJU のすべて / KOMOJU の種類：credit_card・paypay・konbini など）。何も選ばなければどれでも使えます（下記） |
| 会員の項目 | ログイン中の会員の項目（会員ランク・メルマガの同意など）がどれかに合うときだけ使える（下記、0049） |
| 有効 | 外すと、期間内でも使えません（いったん止めたいとき） |

### 支払い方法の条件（0044）

お客様は確認画面の前に「カード（Stripe）」か「KOMOJU」を選びます。クーポンの支払い方法の条件は、その確認画面と注文の確定で判定します。

- カートの画面では、まだ支払い方法が決まっていないので、値引きを仮に表示します。
- 合わない支払い方法を選ぶと、確認画面で「選んだお支払い方法ではご利用いただけません」と出し、値引きしません。
- KOMOJU の種類（例: `paypay`）で絞ったクーポンを使うと、**KOMOJU の決済ページにもその種類だけを出します**。KOMOJU 決済の設定「受け付ける支払い方法」があれば、その重なりだけです。重なりが無ければ注文に進めません。
- 複数のクーポンを併用するときは、種類を重ねて絞り、重ならなくなるクーポンは後から入れた方を外します。
- Stripe の中の支払い方法（カード・Apple Pay など）までは絞れません（「Stripe」でひとまとめ）。

### 会員の項目の条件（0049）

ショップ設定の「会員の項目」で定義した項目（例: `rank | 会員ランク | select | regular/silver/gold`）を、クーポンの条件に使えます。項目の値は、HubSpot などの CRM が API で写すか、管理画面の「会員」で運営者が入れます（docs/ai-access.md §7）。

- 選択式の項目は印を付けた選択肢のどれか、それ以外の項目はカンマ区切りの値のどれかに合えば対象です。前後の空白と大文字小文字は区別しません。
- 項目を複数指定したときは、全部に合うこと。
- ログインしていない人（ゲスト）と、その項目の値が入っていない会員には使えません（「対象の会員の方だけがご利用いただけます」）。
- 判定はカート・確認画面・確定のすべてで行い、確定時の会員の値で引き直します。

## 3. 購入者から見た流れ

1. カート画面の「クーポンコード」に入力して「適用する」。
   **クーポン付きリンク**（`https://<ドメイン>/<ショップ>/cart?coupon=SUMMER10`）を開くと入力済みになります。メルマガ・LINE・SNS に貼って使えます。編集画面にリンクが出ます。購入リンク（`/<ショップ>/buy?sku=…&coupon=…`）にも付けられます。
2. カートに値引きと、使えないときの理由（「あと 1,200 円で使えます」など）が出ます。
3. 配送先を入れると、最終確認画面に値引きの行と値引き後の支払総額が出ます。送料無料のクーポンはここで送料の額が決まります。
4. 決済ページ（Stripe）にも「クーポン SUMMER10 −¥500」と出て、領収メールにも残ります。

注文の管理画面・注文の CSV・購入者向けの注文照会・取引メールに、値引きの額とコードが残ります。

## 4. 回数の数え方

- 回数は **注文の確定（決済の完了）で使用済み** になります。決済ページで支払わずに閉じた・期限が切れた分は自動で戻ります。
- **キャンセル（返金）すると回数が戻ります**（同じ人がまた使えます）。
- 先着のクーポンは、確認画面を出したあと確定するまでの間に上限に達することがあります。そのときは確定せずに確認画面を出し直し、値引きの無い内容をお見せします。
- ヘッドレス（WordPress などの別のサイトの画面）でも、会員のトークンを付ければ会員限定のクーポンが使えます（docs/headless.md「会員」）。
- 1 人あたりの回数は、**ゲストは注文のメールアドレス**で数えます。別のアドレスを使えばすり抜けられるので、厳密にしたいクーポンは「ログイン中の会員だけ」と組み合わせてください（会員は会員 ID で数えるので、メールアドレスを変えても同じ人です）。
- 全体の上限を後から付けた場合、それまでの使用は数えません（付けた時点からの数）。上限は、使用済み・決済待ちの回数より少なくはできません。

## 5. 注意

- 値引き後の支払額が **0 円** の注文（全額値引き・送料無料）は、決済ページへ行かずにその場で確定します（支払い方法は「なし」）。キャンセルしても返金はありません（回数は戻ります）。
- 値引き後の支払額が **1〜49 円** になる注文は確定できません（決済事業者の最低額は 50 円）。
- 送料無料の「○円以上で送料無料」の判定は、**値引き前の小計** で行います。
- 価格はすべて税込です。値引きは商品ごとに配分して注文の明細にも残します（税率ごとの区分が必要な領収書のため）。
- クーポンを削除しても、使われた注文の値引きの記録は残ります。止めたいだけなら「有効」を外してください。
- 管理画面の JSON 書き出し（バックアップ）には、クーポンの設定と発行したクーポンはまだ含まれません。注文の値引きの記録は含まれます。

## 6. 発行して配る（配布型）

データベースの更新 `0019_coupon_grants` が要ります。キャンペーンの画面の下の **「発行して配る」** で、クーポンを 1 枚ずつ発行します。1 枚で 1 回だけ使えます（キャンペーンの「全体の上限」「1 人あたり」は数えません）。

- **会員に発行**: すべての会員、またはメールアドレスで選んだ会員に 1 枚ずつ。会員のマイページの **「マイクーポン」** に出て、「カートで使う」を押すとカートに入ります。その会員がログインしているときだけ使えます。使っていない同じクーポンを持っている会員には、重ねて発行しません。
- **使い捨てコード**: だれでも 1 回だけ使えるコード（`XXXX-XXXX-XXXX`）を最大 5,000 枚。「使える使い捨てコードの一覧（CSV）」で書き出して、チラシ・同梱物・メールなどで配ります。
- **有効日数**: キャンペーンの「発行したクーポンの有効日数」を入れると、発行した日からその日数で使えなくなります（キャンペーンの終了日が先なら終了日まで）。
- キャンペーンの **コードを空** にすると、発行したクーポンだけで使えるキャンペーンになります（コードを知っている人が誰でも使う、ということが起きません）。
- 決済ページの期限切れ・注文のキャンセルで、使った 1 枚は戻ります。使っていないものは「取り消す」で使えなくできます。
- Banto からは会員にお知らせを送りません。発行したことは、運営者からお知らせください。

## 7. 自動で配る・先着で配る

データベースの更新 `0020_coupon_auto` が要ります（会員機能を有効にしたショップで使えます）。キャンペーンの画面で選びます。

- **自動で配る**:
  - 「会員が初めてログインしたとき（会員登録）」: 新しく会員になったとき、取り込んだ会員なら Banto で初めてログインしたときに 1 枚配ります。
  - 「会員の注文が確定したとき（次回使える）」: 会員の注文が確定するたびに、使っていない同じクーポンを持っていなければ 1 枚配ります。ゲストの注文には配りません。
  - 「発行したクーポンの有効日数」を入れておくと、受け取ってからの期限になります。
- **先着の「クーポンを獲得する」ページ**: チェックを付けると、キャンペーンの画面に獲得ページの URL（`/<ショップ>/coupons/<ID>`）が出ます。お知らせや SNS に貼ってください。ログイン中の会員が 1 人 1 枚もらえ、「全体の上限」を入れておくとその枚数で締め切ります（獲得の時点で数えるので、使うときに取り合いは起きません）。
