# お店で試着（同梱モジュール）

お客様がネットで選んだ商品を、実店舗で試着できるよう取り置く同梱モジュールです（既定 OFF。0025_store_tryon の適用が必要）。
**決済はしません。** ご購入は店舗のレジで行います（試着だけでもかまいません）。

## 1. 使い方

1. ショップ設定 → モジュール →「お店で試着」を ON にします。
2. ダッシュボードの「実店舗」（組織の owner / admin）で、実店舗を登録します。実店舗は組織に 1 つずつ登録し、複数のショップで共有します。
   - 店舗名・住所・電話番号・お客様へのご案内（駐車場・試着室の数など）
   - **営業時間**（曜日ごと）: `10:00-20:00` のように入れます。昼休みがあれば `10:00-13:00, 14:00-20:00`。空にした曜日は **定休日** です。
   - **臨時休業・臨時営業**: 1 行に 1 日か期間。`2026-12-31 休業 年末`、`2026-12-31〜2027-01-03 休業 年末年始`、`2027-01-02 11:00-17:00 初売り`。過ぎた日付は保存のときに消えます。
   - 年末年始などは「実店舗」の **まとめての登録** で、選んだ店舗に一度に入れられます（消すときは日付だけ）。
   - 店舗のメールアドレスと「申し込みがあったら店舗にメールで知らせる」（ON/OFF）。メールアドレスはお客様には見せません。
   - 「お客様の画面に出す」
   - モジュールの画面の「店舗」で、**このショップで使う店舗** と「お店で試着を受け付ける」（倉庫など、案内だけ出して試着を受けない店舗は OFF）・並び順を選びます。
   - 実店舗のスタッフは組織の画面で招待し、店舗ごとに「試着の申し込み」「営業時間・臨時休業」を割り当てます。スタッフはお客様の連絡先を見て状態を進められますが、**EC の在庫に戻すことはできません**（ショップの「実店舗・お店で試着」の項目を持つ人が行います）。
3. 設定で **受付の形** を選びます。
   - **お店におまかせ**: お客様は店舗だけを選びます。ショップの都合で店舗へ送り、届いた日から「取り置きの日数」（既定 7 日）取り置きます。
   - **お客様が来店予定日を選ぶ**: 申し込みの何日後から何日後までの、その店舗の営業日から選びます（定休日・臨時休業の日は選べません）。来店予定日から取り置きの日数だけ取り置きます。
   - 1 回に申し込める点数（既定 5 点）、申し込みの画面に出す案内（例:「店舗へは 3〜5 日でお届けします」）

## 2. お客様の画面

- カートに「お店で試着を申し込む」が出ます → 店舗を選ぶ → （来店日）・お名前・メール・電話・ご要望 → 確認 → 申し込み。
- 店舗を選ぶ画面と、店舗のご案内（`/<ショップ>/stores`）に、**本日の営業**・曜日ごとの営業時間・近い臨時休業 / 臨時営業が出ます。
- 会員でもゲストでも申し込めます（会員は名前・メール・電話が入った状態で始まります）。申し込んだ商品はカートから外れます。

## 3. 在庫

- **申し込みの時点で EC の在庫を減らします**（SQL の関数 `tryon_request` が条件付きで減らします。1 点でも足りなければ申し込みは通りません）。
- 購入されなかった・取り消した・期限切れの申し込みは、申し込みの画面の **「EC の在庫に戻す」** を押したときだけ在庫に戻ります（店舗から倉庫へ戻すかどうかは現場で決まるため。1 回だけ）。店舗で購入されたものは戻しません。

## 4. 状態とお知らせ

| 状態 | 誰が | お知らせ |
| --- | --- | --- |
| 申し込み | お客様 | お客様に受付のメール（店舗の住所・営業時間つき）、店舗に申し込みのメール（ON のとき）、LINE でログインした会員には LINE |
| 店舗へ発送済み | 運営者 | （なし） |
| 取り置き中 | 運営者（期限を決める。既定は休業日を避けて計算） | お客様に「ご試着いただけます（◯月◯日まで）」のメールと LINE |
| 店舗で購入 / 購入なし | 運営者 | （なし） |
| 期限切れ | Cron（取り置きの期限の翌日） | （なし） |
| 取り消し | 運営者 | お客様に取り消しのメールと LINE |

- メールは同梱プラグイン「メール通知」、LINE は「LINE で購入者に知らせる」が送ります。0025 を適用すると、有効にしているプラグインは試着のお知らせも受け取ります。
- hooks: `tryon.requested`・`tryon.updated`（docs/hooks.md）。ペイロードに個人情報は載せません。社内システムへつなぐときは、外部プラグインとして受け取ってください。
- 終わった申し込みの名前・メール・電話は、注文と同じ期間（既定 180 日、`MASK_ORDERS_AFTER_DAYS`）で自動で消します。

## 5. 仕組み（開発者向け）

- `0025_store_tryon.sql`: `stores`（組織の実店舗。anon には読ませない）・`shop_stores`（ショップで使う店舗）・`org_member_stores`（スタッフの項目 tryon / hours）、`shop_store_list`（お客様の画面、公開の列だけ）、`store_set_hours`・`stores_set_special_days`（営業時間・まとめての登録）、`tryon_requests`・`tryon_items`（書くのは関数だけ）、`tryon_request`（service_role）・`tryon_request_detail`・`tryon_update`（ショップの stores か実店舗の tryon）・`tryon_restock`（ショップの stores だけ）・`tryon_expire`・`mask_tryon_requests`（Cron）・`tryon_contact`・`tryon_line_recipient`（プラグイン）。
- 営業日の計算は `src/modules/store-tryon/index.ts`（データ取得なし。日付はショップの時間帯）。メールの文は `mail.ts`、管理画面は `admin.tsx`（ショップ）・`stores-admin.tsx`（組織の実店舗・スタッフ、`/admin/stores`）・`requests.tsx`（申し込みの一覧と 1 件、共通）、ストアフロントは `src/routes/storefront/index.tsx` の `/tryon`・`/stores`。
- テーマ: `StoresPage`・`TryonPage` は任意（省略したテーマでは出ません）。営業時間はルートが計算して `StoreView` で渡します。
- ヘッドレス API（`/api/shops/<shop>/stores`・`/tryon`・会員の `/members/tryon`、docs/headless.md「お店で試着」）と AI 用の操作（docs/ai-access.md、0026）。会員ページには自分の申し込みが出て、取り置きが終わる前なら取り消せます（在庫はショップの担当者が「EC の在庫に戻す」を押したときに戻ります）。
- `0027_tryon_shop_names.sql`: `tryon_store_shops`（スタッフの申し込みの一覧に出すショップ名。その店舗の tryon の項目を持つ人に、名前と id だけ）。
- `0026_tryon_api.sql`: `api_tryon_*`・`api_stores_list`・`api_tryon_request_restock`（AI）、`member_tryon_requests`・`member_tryon_cancel`（会員）。状態の遷移は `banto_tryon_transition`、在庫を戻すのは `banto_tryon_restock` の 1 か所ずつ（管理画面と AI が同じものを通る）。在庫を EC に戻せるのは、ショップの「実店舗・お店で試着」の項目を持つ人と、orders:write の AI 用トークン（実店舗のスタッフは不可）。
