# 送り状 CSV（ヤマト運輸・佐川急便）

支払い済みで未発送の注文から、送り状ソフトに取り込む CSV を作る同梱モジュールです（既定 OFF）。

## 1. 使い方

1. ショップ設定 → モジュール →「送り状 CSV（ヤマト・佐川）」を ON にします。
2. モジュールの画面で、ご依頼主（名前・電話番号・郵便番号・住所）と品名を入れます。ヤマトを使うなら、送り状種類（既定 0 = 発払い）・ご請求先顧客コード・運賃管理番号（既定 01）も入れます。
3. 出荷予定日を選んで「ヤマト運輸（B2 クラウド）の CSV」か「佐川急便（e飛伝Ⅲ）の CSV」を押すと、CSV（Shift_JIS）を保存します。
   - 対象は **支払い済み（未発送）** の注文、古い順に最大 500 件です。
   - 配送日時の指定（docs/delivery-time.md）があれば、お届け日と時間帯も載ります。
   - Shift_JIS に無い文字（絵文字など）は「?」にして画面に出します。住所が長すぎる・電話番号が無いなどの注文も画面に出します。

## 2. 取り込み

- **ヤマト運輸 B2 クラウド**:「外部データから発行」で取り込みます。CSV は B2 クラウドの「送り状発行データレイアウト（入出力用）」の 97 項目の順で、1 行目が項目名です（取込開始行を 2 にします）。
  - 日付は `YYYY/MM/DD`、配達時間帯は `0812`（午前中）/ `1416` / `1618` / `1820` / `1921`。
- **佐川急便 e飛伝Ⅲ**: 初回だけ、CSV の 1 行目（見出し）と e飛伝Ⅲ の項目を対応付けた **取込パターン** を作り、「先頭のレコードを除外する」をオンにします。以後はそのパターンで取り込めます。
  - 見出し: お客様管理番号・お届け先電話番号・お届け先郵便番号・お届け先住所1〜3・お届け先名称1〜2・ご依頼主電話番号・ご依頼主郵便番号・ご依頼主住所1〜2・ご依頼主名称1・品名1・出荷個数・配達日・配達指定時間帯。
  - 配達日は `YYYYMMDD`、配達指定時間帯は `00`（指定なし）/ `01`（午前中）/ `14` / `16` / `18` / `19`（18・19 は 6 時間帯の契約で使えます。佐川急便の区分値の資料による）。

お客様管理番号には Banto の注文番号が入ります。

## 3. 送り状番号の取り込み（発送済みにする）

送り状を発行したら、番号を Banto に戻せます（0022_tracking の適用が必要）。

1. B2 クラウド・e飛伝Ⅲ で **発行済みのデータを CSV で書き出し** ます（お客様管理番号と伝票番号・お問い合わせ送り状番号を含む形）。
2. モジュールの画面の「送り状番号の取り込み」で CSV を選びます。Shift_JIS でも UTF-8 でも読めます。
3. 見出しから「注文番号の列（お客様管理番号）」「お問い合わせ番号の列」「運送会社」を推測して表示します。違っていれば選び直して「取り込む」を押します。
   - 支払い済みの注文は **発送済み** になり、お問い合わせ番号が残ります（`order.shipped` が動くので、メール通知・LINE 通知が届きます）。
   - 発送済みの注文は番号だけ入れ直します（もう一度は知らせません）。
   - キャンセル済み・見つからない注文番号は画面に出します。番号として読めない行（英数字 4〜40 文字でない）は数だけ出します。
   - 1 回に送るのは 500 行ずつです（それ以上はブラウザが分けて送ります）。

1 件ずつなら、注文の画面でも運送会社とお問い合わせ番号を入れて発送済みにできます。

番号は購入者の注文照会と発送のメールに、運送会社の照会ページへのリンクつきで載ります（ヤマト運輸・佐川急便・日本郵便。照会ページの URL は各社が公開している形で、実機での確認はまだです）。hooks のペイロードには載せません（届け先の地域が分かるため）。

## 4. 仕組み（開発者向け）

- CSV の組み立ては `src/modules/shipping-labels/csv.ts`（データ取得なし）。管理画面が owner の JWT で注文を読み、文字列（CRLF）を JSON で返す。
- Shift_JIS への変換は `src/modules/shipping-labels/client.ts`（ブラウザ。`TextDecoder("shift_jis")` で逆引きの表を作る。全角チルダと波ダッシュなど、見た目が同じ文字は同じコードにする）。`npm run check:client` が本番のバンドルから取り出して確かめる。
- 送り状番号の取り込みも同じ `client.ts`（`decodeBytes` → `parseCsv` → `detectColumns` → `trackingItems`）。Worker は番号の組を受け取って `ship_orders`（0022、owner の JWT、SQL 側で所有と番号の形を検証）を呼ぶだけ。番号の形・照会ページの URL は `src/orders/tracking.ts`。
