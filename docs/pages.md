# ショップのページ（同梱モジュール）

「私たちについて」「よくある質問」「ギフトのご案内」のようなページを作り、お店の画面の `/<ショップ>/pages/<名前>`（独自ドメインでは `/pages/<名前>`）に出す同梱モジュールです（既定 OFF。0079_mod_pages の適用が必要）。

- 本文は**決まった書式**（見出し・太字・リンク・画像・表など。下の「書式」）で書きます。**HTML は書けません**（書いても文字のまま出ます）。
- 並びや見た目はテーマが決めます。既定のテーマはそのまま描き、Liquid のテーマでは `templates/page`（ページごとに `templates/page.<名前>` も選べます。docs/themes.md）で描きます。
- ヘッダーかフッターのメニューに出せます。
- 特定商取引法に基づく表記・プライバシーポリシー・返品ポリシーは今までどおりショップの設定です（このモジュールではありません。公開の条件だからです）。

## 1. 使い方

1. ショップ設定 → モジュール →「ページ」を ON にします。ショップの管理画面に「ページ」のタブが出ます。
2. 「新しいページ」を開くと、左に大きなタイトルと本文、右に「ページの設定」、上に「下書き保存・プレビュー・公開」のボタンが並びます（WordPress の編集の画面に近い形です）。
   - **本文はブロックで組み立てます**: 空の行で `/` を打つと、段落・見出し・小見出し・箇条書き・番号付き・引用・区切り線・表・画像の一覧が出ます（矢印と Enter で選べます）。選んでいるブロックの右上の「＋」で次にブロックを足し、「↑」「↓」で並べ替え、「×」で消せます。本文の下の「ブロックを追加」は最後に足します。
   - 「ビジュアル」（見たまま）と「Markdown」（下の書式を直接書く）を切り替えられます。どちらで書いても、保存するのは同じ書式です。
   - **URL の名前**は、空のままならタイトルから作ります（`About Us` → `about-us`。英数字にならないタイトルは `page-xxxxxx`）。手で入れることもできます。
   - **プレビュー**は新しいタブで開き、保存はしません。見た目はお店のテーマで変わります。
   - **下書き保存**は公開しないで保存、**公開**で公開します。公開中のページは「更新」と「下書きに戻す」になります。Ctrl+S（Mac は ⌘S）で下書き保存（公開中なら更新）。保存していない変更があるときに画面を離れようとすると知らせます。
   - 画像は、ブロックの「画像」か右の「画像を置く」で選ぶと、ブラウザで縮めてから置き場に上げ、本文のその場所に入ります。
3. メニューに出すなら「メニュー」でヘッダーかフッターを選びます。並び順は小さい順です。
4. 組織のスタッフに任せるときは、組織の画面でショップごとに「ページ」の項目を割り当てます（ひな形「ページの担当」）。この項目だけの人は、商品・注文・会員の画面には入れません。

- URL の名前は英小文字・数字・ハイフンで 64 文字まで（先頭と末尾は英数字）。`legal`・`privacy`・`returns`・`shipping`・`cart`・`checkout`・`account`・`search`・`orders`・`inquiries` は使えません。
- 1 つのショップに 100 ページまで。Banto をホスティングして貸す構成では、プランの上限 `plan_limits.pages` でこの Banto 全体の数も決められます。
- 公開したページは、サイトマップ（`sitemap-pages.xml`）に載ります。
- 管理画面の JSON の書き出し（バックアップ）に入ります。空のショップへの復元（`restore_shop_data`）には入りません（ページは書き出しの JSON から手で戻してください）。

## 2. 書式

```
## 見出し
### 小見出し

段落は空の行で分けます。
行の折り返しはそのまま改行になります。

**太字**　*斜体*　`コード`

[リンクの文字](https://example.com)　[送料について](/shipping)

![画像の説明](https://<画像の置き場>/pages/...)

- 箇条書き
- 箇条書き

1. 番号付き
2. 番号付き

> 引用

---

| 見出し | 見出し |
| --- | --- |
| 中身 | 中身 |
```

- `#` と `##` は同じ大きさの見出し、`###` は小見出し、`####` 以下はその下です（ページのタイトルが一番大きい見出しのため）。
- リンクは `https://`・`http://`・`/`（ショップの中）・`#`・`mailto:`・`tel:` から始まるものだけです。ほかは文字のまま出ます。外へのリンクには `rel="noopener"` が付きます。
- 画像は**ショップの画像の置き場のものだけ**です（外のサイトの画像は文字になります。お客様の閲覧を外に知らせないため）。編集の画面の「画像を置く」で置くと、本文に `![](URL)` が入ります。大きな画像はブラウザで長辺 1600px の WebP に縮めてから送ります。SVG は置けません。
- 記号をそのまま出したいときは前に `\` を付けます（`\*`）。
- 本文は 50,000 文字まで。

### 商品を並べる・ボタン（1 行のブロック）

編集の画面では `/` の一覧の「商品を並べる」「ボタン」から入れます（商品のブロックは押すと設定を直せます）。書式では次の 1 行です。

```
::: products category=tops tag=冬物 limit=8 layout=grid sort=new
::: button [すべての商品を見る](/p/coat)
```

| 設定 | 値 | 既定 |
| --- | --- | --- |
| `category` | カテゴリーの URL の名前（子のカテゴリーの商品も含む） | すべて |
| `tag` | このタグを持つ商品だけ（空白を含むなら `tag="冬 物"`） | 絞らない |
| `limit` | 1〜24 | 8 |
| `layout` | `grid`（並べる）・`scroll`（横スクロール） | `grid` |
| `sort` | `new`（新しい順）・`updated`・`price_asc`・`price_desc`・`name` | `new` |

- 並ぶのは**公開中の商品だけ**です（商品の一覧と同じ選び方とキャッシュ）。値段・在庫は商品の一覧と同じく、描いた時点のものです。
- 1 ページに **3 つまで**（4 つ目からは描きません）。1 つのブロックはお店の画面で問い合わせ 1 回（ブロックどうしは並列、2 回目からはキャッシュ）。
- 見た目はテーマが決めます。Liquid のテーマは `snippets/page-products.liquid` に `products`（一覧の形の商品）と `block`（`layout`・`limit`・`sort`・`category`・`tag`・`index`）を渡して描き、無ければ Banto の既定のカード（`ul.banto-products__list`）を出します（docs/themes.md）。
- ボタンのリンクの規則は本文のリンクと同じです。HTML は `<p class="banto-button"><a class="banto-button__link" href="…">文字</a></p>` で、見た目はテーマの CSS です。
- 文字として `:::` で始めたいときは前に `\` を付けます（`\:::`）。

## 3. 安全のための作り

- 「ビジュアル」の編集はブラウザの中だけで、保存するときに上の書式に直して送ります（`src/modules/pages/editor-client.ts`）。書式で表せない飾り（文字の色・大きさなど）は文字だけが残ります。貼り付けは文字だけです（ほかのサイトの見た目やスクリプトを持ち込まない）。JS の無いブラウザでは「Markdown」の入力欄だけになります。

- 本文を HTML にするのは**お店の画面を描くとき**です（`src/pages/markdown.ts`）。DB には書いた文字だけを置き、HTML は置きません。だから「ページ」の項目を持つ人でも、ショップのドメインに任意の HTML やスクリプトを入れられません（テーマの JS を入れられるのは「デザイン（テーマ）」の項目だけです。docs/themes.md）。
- 変換は文字を 1 回なめるだけで、長い入力でも遅くなりません。変換した HTML は Worker のメモリにページの版ごとに覚え、同じページを描くたびには変換しません。
- 下書きのページはお客様から見えません（DB の RLS）。モジュールが OFF のショップでは、公開中のページも出しません。

## 4. お店の画面の使い方との関係

お店の画面の使い方（docs/storefront.md）が「カートと購入だけ」「使わない」のショップでは、ページを出さず外のサイトへ回します（商品の一覧と同じ扱い。ページは外のサイトが持つため）。
